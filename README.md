# Linux-Systems-Interactive
This project was developed as part of a university assignment focused on learning and practicing fundamental Linux concepts.

It is an interactive Bash-based application organized into multiple modules, each covering a different area of Linux system administration and command-line usage. The project includes practical examples and interactive exercises for topics such as file and directory management, user and permission administration, process monitoring, hardware resources, software packages, networking, C compilation with GCC, Bash scripting, and text processing.

The application uses a menu-based terminal interface that allows the user to navigate between the different modules and execute Linux commands while seeing their results directly in the terminal.

Main topics covered
Linux command-line fundamentals
Files and directories
Users, groups, passwords, and permissions
Process and service management
CPU, RAM, kernel, and hardware information
Package management using APT and DPKG
Networking tools such as ip, ping, ss, nslookup, and curl
C compilation using GCC
Bash scripting concepts
Text processing using tools such as grep, sort, wc, cut, and pipelines

The project is structured into separate Bash scripts for each module and uses a main script to load the modules and provide an interactive menu.

This project was created for university purposes as a practical way to better understand Linux commands, shell scripting, and basic system administration.
